### oi, sou o Matheus.

Pego uma ideia meio torta e transformo em algo que dá pra usar.
Rust, C#, Python, Dart, Java: o que a ideia pedir.
Se eu uso todo dia, vira ferramenta.

- [ByteBapo](https://github.com/MatheusANBS/ByteBapo): IA local no celular, pelo Wi-Fi de casa, sem nuvem.
- [Wireless-Automate](https://github.com/MatheusANBS/Wireless-Automate): mod de Minecraft que move item, fluido e energia sem pipe nem cabo.
- [TTT](https://github.com/MatheusANBS/TTT): scanner de memória de processos no Windows, em tempo real.
- [COMPLAT](https://github.com/MatheusANBS/COMPLAT): acha arquivos por lista e zipa em lotes do tamanho certo.

**Privados, mas que me dão orgulho**

- **DBZ**: cliente de banco de dados pro desktop, na linha do DBeaver, só que leve. Rust, Tauri, React e um grid próprio em canvas.
- **Argos**: servidor MCP em C++23 pra depurar memória de processos em runtime, com autorização explícita pra cada sessão e cada escrita.
- **scry**: app desktop em Rust pra inspecionar a memória de processos, rodando sobre o mesmo motor de um servidor MCP. A interface é HTML e CSS numa WebView, e quem faz todo o trabalho é o Rust.
